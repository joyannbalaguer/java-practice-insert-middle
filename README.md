# Java Practice (1) – Insert in Middle (Linked List)

## Description
This project demonstrates a Java practice implementation of inserting a node in the middle of a singly linked list.
It shows how linked list traversal and pointer manipulation work when adding elements at a specific position.

## Features
- Create a singly linked list
- Insert elements at the end of the list
- Insert a new node in the middle of the list
- Display the list before and after insertion

## Purpose
This project is created for practice and learning purposes to understand linked list operations in Java.
